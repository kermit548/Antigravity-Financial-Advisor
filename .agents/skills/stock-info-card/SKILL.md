# 股票戰情卡生成技能

本技能是用於將個股的解析結果（包括價格、波動因子、技術支撐壓力、基本與籌碼風險、綜合評級結論、催化劑、未來劇本、策略計畫及主要風險）渲染為一張精美的高解析度卡片（`output/stock_<代碼>_<時間戳記>.png`），以提供客戶直觀且專業的視覺報告。

## 觸發與呼叫流程
在執行「個股資訊解析工作流（模式 3）」完畢後，作為協調人的 Agent 必須自動整理結構化分析數據，並透過命令行呼叫底層的繪圖腳本：

```bash
python .agents/skills/stock-info-card/scripts/generate_stock_card.py \
  --symbol "<股票代號>" \
  --name "<公司官方全銜>" \
  --price <最新收盤價/現價> \
  --change "<漲跌幅與變動點數，例如 +0.58 (+3.35%)>" \
  --score <評分分數 0-100> \
  --regime "<市場狀態，例如 A/B/C/D>" \
  --trend "<趨勢，例如 偏多/震盪/偏空>" \
  --risk "<風險，例如 低/中/高>" \
  --conclusion "<核心結論文字>" \
  --valuation "市值: <市值> | Beta: <Beta> | 近 52 週區間: <低~高>" \
  --levels "壓力:<價格區間>|短支:<價格區間>|中支:<價格區間>|守門:<價格區間>|危險:<價格臨界>" \
  --tactics "動作:<ENTER/WAIT>|建議倉位:<比例>|金額:<金額>|第1批:<價格/比例>|第2批:<價格/比例>|第3批:<價格/比例>|停損:<停損價>|停利:<停利價>" \
  --catalysts "1.<催化劑一>;2.<催化劑二>;3.<催化劑三>;4.<催化劑四>" \
  --scenarios "強勢 <機率>:<區間>|中性 <機率>:<區間>|防守 <機率>:<區間>" \
  --risks "<風險點一>;<風險點二>;<風險點三>;<風險點四>"
```

## 輸出路徑與格式
* 產出之 PNG 圖片將一律儲存在專案的 `output/` 目錄中。
* 命名規範為：`output/stock_<輸入代碼>_<時間戳記>.png`（時間戳記格式為 `YYYYMMDD_HHmmss`）。
* 在對話回覆末尾，必須強制提供該圖片的實體下載路徑，並使用 markdown 語法內嵌展示該卡片。

## 防錯與降級協議
1. **依賴自動安裝**：繪圖腳本具備自動偵測機制，若執行環境缺少 `yfinance` 或 `matplotlib`，會自動在背景嘗試使用 `pip` 安裝，無需使用者手動介入。
2. **K 線數據降級**：若因網路受阻無法下載 Yahoo Finance 歷史日線，或是 `matplotlib` 繪圖引擎出錯，將自動啟動「防錯降級機制」：Pillow 會繪製不含中間 K 線圖的純文字/表格戰情卡，並在卡片底部附帶警示標註，保證整個工作流不崩潰、不中斷。
3. **中文字型處理**：為避免中文字渲染出現豆腐塊，腳本會自動掃描系統常見中文字型，並提供防錯替代字型。
