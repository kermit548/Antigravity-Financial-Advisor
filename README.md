# 升級版財經小智工作流專案

這個專案將原先在 Google Gemini 網頁介面的「財經小智」Gem 升級為本地的 Agent 專案。

## 功能特色
1. **複利與金流精確計算**：整合 Python 數學計算腳本，徹底解決大型語言模型硬算複利、利率與提領金流容易產生的誤差。
2. **理財建議書實體 Word 輸出**：自動將試算結果、投資比率分配與年度複利累積表匯出為格式優雅的 Word 建議書 (`.docx`)。
3. **指南 PDF 對齊**：專案 `input/` 資料夾中直接整合了另類投資、固定收益、結構型商品與重要稅負的最新指南 PDF。

## 資料夾說明
- `input/`：存放另類投資指南、固定收益指南、SN/DRA 商品介紹、重要稅負指南等 6 份核心參考 PDF。
- `output/`：產出之理財建議書將儲存於此。
- `scripts/`：放置金融計算與自動化 Word 產檔腳本 `financial_calc.py`。
- `.agents/`：放置 Agent 顧問技能指引 SKILL.md。

## 使用方式
直接在 AntiGravity / Claude Code 中開啟此專案目錄，Agent 將自動載入並進入「財經小智」理財顧問模式，依據 `AGENTS.md` 與 `SKILL.md` 規範為客戶提供精確諮詢。
