# 財經小智 Agent 智慧理財工作流專案

這個專案是將 Google Gemini 網頁介面的「財經小智」Gem，升級重構而來的本地多 Agent 協同理財顧問專案。

本專案固定了理財規劃建議書的計算規格與產出流程，並以客戶資料、理財目標、即時市場數據與核心知識庫為浮動輸入，能自動生成科技風格的玻璃擬態（Glassmorphism）互動簡報 HTML 建議書。

---

## 核心特色與工作流模式

| 模式 | 工作流名稱 | 核心功能與執行步驟 |
| :--- | :--- | :--- |
| **模式 1** | **法人視野市場分析** | 當偵測到「法人視野、聰明錢、SMC」等關鍵字時，由法人分析師擷取全球市場數據，執行 SMC 技術結構分析，並提供非財經背景大學生也能讀懂的「囤貨倉庫（訂單塊）」與「空氣裂縫（FVG）」白話分析。 |
| **模式 2** | **當前風險評估** | 當提到「風險評估、逆向思考、對沖」等關鍵字時，由風險管理師評估系統性與非系統性風險，實施金融與心理之「雙軌分析」，並具備網頁連結失效之防錯降級機制。 |
| **模式 3** | **個股資訊解析** | 輸入個股或代號後，啟動雙來源（Google & Yahoo Finance）交叉取價驗證。確認現價未脫離 52 週合理區間且具備 3 天內時效，並基於波特五力分析給出 **[A] 傳世資產** 至 **[E] 極度危險** 的五級投資評級。 |
| **模式 4** | **今日財經新聞** | 抓取每日台美股行情、匯率、美債殖利率、金價與加密貨幣指標。自動精選分類新聞，並依據台銀金價與國際金價公式，**精確計算新台幣-黃金折溢價價差**。 |
| **模式 5** | **團隊資產會診** | 啟動理財專家聯席診斷，收集四方專家觀點，由協調人（主顧問）彙整為診斷報告，並自動編譯為互動式 HTML 簡報。 |
| **`/generate_plan`** | **規劃書簡報產出** | 輸入客戶儲蓄與報酬率參數，自動調用生圖工具批次生成 8 張科技感插圖，並呼叫計算腳本進行複利與 4% 提領計算，一鍵編譯成 Base64 內嵌、可立即線上分享的霓虹科技風格簡報 HTML。 |

## 投資團隊專家天團

在進行 **模式 5 團隊資產會診** 時，主協調人將調用以下四位專家進行會診：

| 專家角色 | 核心定位 | 底層思維模式 | 風格特色 |
| :--- | :--- | :--- | :--- |
| **指數投資專家** | 全球極低成本被動配置，獲得公平市場回報。 | 成本效益假說（CMH）、買下整個草堆、均值回歸、不動如山。 | 親切溫和、有耐心，涉及中介收費與投機時展現堅定的常識批判。 |
| **法人視野分析師** | 追蹤產業鏈供需、資本支出（CAPEX）瓶頸與聰明錢足跡。 | 拒絕猜底與順勢而為，專注物理產能瓶頸與結構性變革。 | 數據即信仰，抱持法人冷靜審視態度（Cynicism），邏輯先於股價。 |
| **逆向風險管理師** | 結合財務風控與世俗智慧的決策雙軌過濾器。 | 理性金融軌道與心理認知軌道（激勵審查、心理誤判、避免愚蠢）。 | 語氣嚴謹且邏輯尖銳，具備行動導向，並融入逆向思考與經典比喻。 |
| **槓桿思維大師** | 施加財務與產品槓桿以取得時間與財務自由。 | 50/50 財務槓桿與再平衡，配合無許可槓桿、專長與評判力優先。 | 自信且具備煽動力（大仁氣場），同時融入納瓦爾式禪意與極簡理性。 |

## 數據誠信與風控機制

*   **拒絕模型估算複利**：所有年化複利與提領試算，必須調用 `scripts/financial_calc.py` 腳本，嚴格執行數據誠信。
*   **知識庫優先**：回答另類投資、固定收益、結構商品與稅負問題時，強制讀取 `input/` 下對應的官方指南 PDF，禁止幻覺。
*   **FBI 投資戰術矩陣**：當偵測到 FBI 數據或市場觀測時，自動啟動情緒燈號對照協議（白色/淡紫色/深紫色/綠色），要求在綠燈與紫燈時提示散戶以長期閒置資金配置之思維。
*   **隱私保護**：客戶個人資料與產出之建議書檔案均存於 `output/` 之中，已設定 Git 忽略，**嚴禁上傳至公開的 GitHub 倉庫**。

---

## 資料夾說明

*   `input/`：存放使用者自定義的核心參考 PDF 知識庫（如另類投資、固定收益、重要稅負與結構商品說明文件）。
*   `output/`：產出之理財建議書與診斷簡報 HTML（受 Git 忽略）。
*   `scripts/`：放置金融計算與自動化 HTML 簡報編譯腳本。
*   `.agents/`：存放主顧問與四位子 Agent 專家技能指引（SKILL.md）。

> 本專案環境建議先安裝三師爸製作的 [Anti-Gravity 懶人包](https://github.com/mathruffian-dot/antigravity-lazy-pack)。
